# Odds Display

> Learn how to switch between percent and price display in the app

**1. Open odds settings**

Open the **Portfolio** tab, tap the settings icon at the top right, then tap **Odds format**.

**2. Choose display format**

Select **Price** (¢) or **Percent** (%).

**3. View updated odds**

Your selected display format applies across all markets.

***

## Example

In a live Washington vs. Kansas City market:

| Display Type | Example |
| - | - |
| Price | WAS 17¢ / KC 86¢ |
| Percent | WAS 17% / KC 86% |

> [!NOTE]
>
> All display formats show the same market information — only the way it's shown changes.
